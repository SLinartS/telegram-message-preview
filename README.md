# Telegram Message Preview

Предпросмотр текстовых сообщений в стиле Telegram с поддержкой Markdown, HTML и экспортом разметки для Bot API. Работает локально, без зависимостей, сборки и внешних запросов.

## Возможности

- Предпросмотр сообщения при вводе текста.
- Режимы Markdown, HTML и обычного текста.
- Панель форматирования, спойлеры, цитаты, код и ссылки.
- Светлая и тёмная темы чата.
- Счётчик длины сообщения и предупреждение при превышении 4 096 символов.
- Экспорт HTML для `parse_mode: "HTML"`.
- Сохранение черновика и настроек в localStorage браузера.

## Запуск

Нужен Node.js 20+; рекомендуемая версия 24 указана в `.nvmrc`. Устанавливать зависимости для запуска не требуется.

```sh
npm start
```

Откройте [localhost:4173](http://localhost:4173). Для другого порта: `PORT=4174 npm start`.

## Форматирование

- **Markdown** использует синтаксис Telegram: `*жирный*`, `_курсив_`, `__подчёркнутый__`, `~зачёркнутый~`, `||спойлер||`, код, блоки кода, ссылки, цитаты через `>`. Для удобства вставки черновиков также понимает `**жирный**` и `~~зачёркнутый~~`; это расширение, не синтаксис MarkdownV2.
- **HTML** поддерживает базовые теги Bot API, включая `tg-spoiler`, `pre`, `code` и `blockquote`. Неподдерживаемые теги вызывают предупреждение; произвольный HTML не исполняется.
- **Текст** показывает сообщение без разбора разметки.

Синтаксис: [Telegram Bot API — Formatting options](https://core.telegram.org/bots/api#formatting-options).

## Ограничения

Это визуальная имитация базовых текстовых сообщений, а не Telegram и не валидатор Bot API. Markdown-предпросмотр терпим к неэкранированной пунктуации и незакрытым маркерам. Для отправки через бота копируйте HTML из блока экспорта. Обычная вставка Markdown в клиент Telegram не равна отправке через Bot API с parse_mode. Дизайн и переносы зависят от клиента, шрифта и ширины. Медиа, превью сайтов, premium emoji и новые rich messages не моделируются. Заголовки, таблицы и прочие возможности общего Markdown не поддерживаются.

Текст не отправляется на сервер. Кнопка «Очистить» удаляет текущий текст и сохранённый черновик.

## Разработка

```sh
npm run check
npm test
```

`check` проверяет синтаксис JavaScript, `test` запускает тесты парсера через встроенный Node.js test runner. HTML-парсер использует браузерный `DOMParser`; текущие автоматические тесты покрывают Markdown, ссылки и HTML-экспорт.

CI запускает эти проверки на Node.js 20, 22 и 24.
